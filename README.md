## What is OpenCV?

OpenCV is a free, open-source CV builder that turns one master career profile into unlimited tailored CVs and matching cover letters. No design skills needed. No paywall. No watermarks.

**Why it exists:** Most CV builders lock templates behind paid plans. OpenCV gives you 20+ professional templates, real-time previews, and one-click PDF export — all free.

## Quick Start (5 minutes)

```bash
# 1. Clone
git clone https://github.com/swadhinbiswas/cv.git
cd cv

# 2. Install
bun install

# 3. Setup
cp .env.example .env.local

# 4. Run
bun run dev
```

Open **http://localhost:3000** → Sign up → Build your first CV.

## CV Writing Tips (from Career Experts)

### The 6-Second Rule

Recruiters spend **6–7 seconds** on an initial CV scan. Your CV must pass this test:

1. **Name and headline** — immediately clear who you are
2. **Most recent role** — current title, company, 2–3 bullet points
3. **Skills section** — keywords that match the job description
4. **Education** — degree, institution, year

### Quantify Everything

❌ "Improved application performance"
✅ "Reduced API latency by 40% serving 2M+ monthly users"

❌ "Managed a team"
✅ "Led a 6-person engineering team that shipped a self-serve reporting product adopted by 500+ organisations"

**Formula:** Action verb + What you did + Measurable result

### Action Verbs That Work

| Category | Verbs |
|----------|-------|
| **Leadership** | Led, Directed, Spearheaded, Orchestrated, Championed |
| **Achievement** | Delivered, Achieved, Exceeded, Surpassed, Earned |
| **Technical** | Architected, Implemented, Optimised, Automated, Deployed |
| **Communication** | Presented, Authored, Negotiated, Facilitated, Advocated |
| **Analysis** | Analysed, Evaluated, Assessed, Researched, Investigated |

### Tailor Every Time

The #1 mistake: sending the same CV to every job. For each application:

1. **Read the job description** — identify 5–10 keywords
2. **Mirror their language** — if they say "cross-functional teams," use that phrase
3. **Reorder sections** — put the most relevant section first
4. **Adjust your headline** — match the job title exactly

## ATS (Applicant Tracking System) Guide

75% of resumes are rejected by ATS before a human sees them. Follow these rules:

### Do

- ✅ Use **standard section headings** ("Work Experience," "Education," "Skills")
- ✅ Use **single-column layout** — ATS parsers read left-to-right, top-to-bottom
- ✅ Use **simple fonts** — Arial, Calibri, Georgia, Times New Roman
- ✅ Use **reverse chronological order** — most recent first
- ✅ Include **keywords from the job description** — exact matches matter
- ✅ Use **dates in MM/YYYY format** — e.g., "01/2024" or "January 2024"

### Don't

- ❌ Use **tables or columns** — ATS often can't parse them
- ❌ Use **headers/footers** for contact info — many ATS skip them
- ❌ Use **fancy fonts** or **graphics** — they break parsing
- ❌ Use **"My Journey"** as a section title — use "Work Experience"
- ❌ Put **contact info in the header** — put it in the body
- ❌ Use **photos** — many ATS ignore images entirely

### ATS Score Checklist

| Item | Target |
|------|--------|
| Standard section headings | 100% |
| Single-column layout | 100% |
| Reverse chronological | 100% |
| Keywords from job description | 75%+ match |
| Quantified achievements (numbers, %) | At least 3 |
| Action verbs | At least 5 |
| No tables/graphics | 100% |
| Clean formatting | 100% |

OpenCV's **ATS Score Panel** checks all of these automatically.

## Section Order by Career Stage

### Entry-Level / Recent Graduate
1. Education (first — you have the most relevant coursework)
2. Skills (technical abilities matter early)
3. Experience (internships, part-time work)
4. Projects (personal projects, open source)
5. Certifications

### Mid-Career Professional
1. Summary (2–3 sentences positioning yourself)
2. Experience (reverse chronological, quantified)
3. Skills (grouped by category)
4. Education
5. Certifications / Projects

### Senior / Executive
1. Summary (leadership positioning, 3–4 sentences)
2. Experience (focus on impact and metrics)
3. Education
4. Awards / Recognition
5. Board Memberships / Volunteer

### Academic / Research
1. Summary / Research Interests
2. Education
3. Publications (most important for academia)
4. Research Experience
5. Teaching Experience
6. Grants & Awards
7. Skills / Languages

## Cover Letter Tips

### When to Send a Cover Letter

- **Always** — 72% of hiring managers expect one
- **Especially** when the job posting asks for one
- **When** you're changing careers or have a gap to explain

### Structure (3–4 Paragraphs)

1. **Opening** — State the role, how you found it, and why you're excited (1–2 sentences)
2. **Body** — Connect your experience to their needs. Use 1–2 specific examples with metrics.
3. **Closing** — Restate your interest, mention your CV, and express enthusiasm for an interview.

### Tone

- Professional but not stiff
- Enthusiastic but not desperate
- Specific but not lengthy (under 400 words)
- Address the hiring manager by name when possible

## Environment Variables

See `.env.example` for the full list. Key variables:

| Variable | Required | Description |
|----------|----------|-------------|
| `AUTH_SECRET` | Yes | Session signing key. Generate: `openssl rand -base64 32` |
| `DATABASE_URL` | Yes | `file:./dev.db` locally, Turso URL in production |
| `NEXT_PUBLIC_FIREBASE_*` | No | Firebase client config (for Google sign-in) |
| `FIREBASE_*` | No | Firebase service account (for server-side auth) |
| `PDF_WORKER_URL` | No | Cloudflare PDF worker URL |
