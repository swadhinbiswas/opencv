## 1. What is OpenCV?

OpenCV is a free, open-source online CV builder and cover letter maker. It allows
job seekers to create professional, ATS-friendly resumes and cover letters without
design skills or paid subscriptions.

**Core concept:** Users fill in a single "master profile" containing all their
work experience, education, skills, projects, certifications, and references. From
this one profile, they can generate unlimited tailored CVs by switching templates,
reordering sections, and adjusting themes — all without retyping content.

**Key differentiator:** Every template on the site is rendered as a real,
live preview (not a placeholder image). What users see in the browser is exactly
what they get in the exported PDF.

## 3. CV Writing Guidance

### 3.1 The 6-Second Rule

Recruiters spend 6-7 seconds on an initial CV scan. A CV must immediately show:
1. Name and professional headline
2. Most recent role (title, company, 2-3 bullet points)
3. Skills section matching the job description
4. Education (degree, institution, year)

### 3.2 Quantify Achievements

Weak: "Improved application performance"
Strong: "Reduced API latency by 40% serving 2M+ monthly users"

Weak: "Managed a team"
Strong: "Led a 6-person engineering team that shipped a self-serve reporting
product adopted by 500+ organisations"

Formula: Action verb + What you did + Measurable result

### 3.3 ATS Best Practices

Do:
- Use standard section headings (Work Experience, Education, Skills)
- Use single-column layout
- Use simple fonts (Arial, Calibri, Georgia, Times New Roman)
- Use reverse chronological order
- Include keywords from the job description
- Use dates in MM/YYYY or Month YYYY format

Don't:
- Use tables or columns (ATS parsers can't read them)
- Use headers/footers for contact info (many ATS skip them)
- Use fancy fonts or graphics
- Use creative section titles ("My Journey" instead of "Work Experience")
- Include photos

### 3.4 Section Order by Career Stage

Entry-Level / Recent Graduate:
1. Education (coursework is most relevant)
2. Skills (technical abilities)
3. Experience (internships, part-time)
4. Projects (personal work, open source)
5. Certifications

Mid-Career Professional:
1. Summary (2-3 sentences)
2. Experience (reverse chronological, quantified)
3. Skills (grouped by category)
4. Education
5. Certifications / Projects

Senior / Executive:
1. Summary (leadership positioning)
2. Experience (impact and metrics)
3. Education
4. Awards / Recognition
5. Board Memberships / Volunteer

Academic / Research:
1. Summary / Research Interests
2. Education
3. Publications
4. Research Experience
5. Teaching Experience
6. Grants & Awards
7. Skills / Languages

### 3.5 Cover Letter Structure

1. Opening — State the role, how you found it, and why you're excited (1-2 sentences)
2. Body — Connect experience to their needs. Use 1-2 specific examples with metrics.
3. Closing — Restate interest, mention CV, express enthusiasm for an interview.

Length: Under 400 words. Tone: professional but not stiff, enthusiastic but not
desperate.

## 4. Technical Architecture

### 4.1 Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI:** React 19, Tailwind CSS v4, shadcn/ui
- **Auth:** Firebase Auth (client) + jose JWT (server)
- **Database:** libSQL/Turso via Drizzle ORM
- **PDF Generation:** Puppeteer via Cloudflare Browser Run worker
- **Fonts:** Google Fonts CDN (EB Garamond, Gentium Book Plus, Inter, JetBrains
  Mono, Lato, Raleway, Ubuntu)
- **Hosting:** Cloudflare Pages + Workers

### 4.2 API Routes

- POST /api/auth/signup — Create account (dev mode: email/password)
- POST /api/auth/login — Sign in
- POST /api/auth/session — Get current session
- POST /api/auth/logout — Sign out
- POST /api/demo — Seed sample data
- GET /api/templates — List all templates
- GET /api/cvs — List user's CVs
- POST /api/cvs — Create new CV
- PATCH /api/cvs/[id] — Update CV (template, settings)
- PATCH /api/cvs/[id]/sections — Update section order/visibility
- GET /api/cover-letters — List cover letters
- POST /api/cover-letters — Create cover letter
- GET /api/export?kind=pdf|docx|txt&scope=cv|letter|bundle&id=xxx — Export document
- GET /api/profile — Get master profile
- PATCH /api/profile/[section] — Update profile section
- POST /api/profile/reorder — Reorder profile sections
- POST /api/profile/bullets — Manage experience bullet points
- GET /api/jobs — List job applications
- POST /api/jobs — Create job application
- PATCH /api/jobs/[id] — Update job application
- PATCH /api/jobs/[id]/events — Add events to job application
- PATCH /api/jobs/[id]/status — Update application status
- GET /api/account — Get account info
- DELETE /api/account — Delete account
- GET /api/account/export — Export all user data

### 4.3 Database Schema

Key tables:
- users — User accounts (id, email, name, firebaseUid)
- masterProfiles — Career profiles (linked to user)
- profiles — Profile sections (summary, experience, education, skills, etc.)
- cvs — User's CVs (linked to template, has settings/theme overrides)
- cvSections — Section configuration per CV (order, visibility)
- templates — Available templates (id, name, formatType, layoutSchema, themeTokens)
- coverLetters — User's cover letters (linked to template)
- jobs — Job applications (kanban board)

### 4.4 CV Rendering Engine

The CV renderer (src/lib/cv/render.tsx) is a React component that:
1. Takes format (layout type), theme (colours, fonts), and sections as input
2. Partitions sections into main/side columns based on layout config
3. Renders header (standard, centered, band, or split variant)
4. Renders sections with items (title, subtitle, badge, bullets)
5. Applies format-specific CSS (small-caps, colour bars, skill chips, etc.)

Supported layout variants:
- Header: standard, centered, band, split
- Body: single, sidebar, rightrail
- Compact mode for ATS/academic layouts

## 6. Privacy & Security

- User data (CVs, cover letters, personal info) is stored in the database and
  is never accessible to AI crawlers
- All routes under /dashboard, /profile, /cv, /cover-letters, /jobs, /api are
  private and excluded from crawling
- Authentication uses Firebase Auth (client) and jose JWT (server)
- Session tokens are signed with a server-side secret
- Account deletion removes all user data from the database

## 9. FAQ for AI Reference

Q: Is OpenCV free?
A: Yes, completely free. No credit card, no trials, no watermarks.

Q: What templates are available?
A: 20+ CV templates and 7 cover letter templates, covering ATS, classic, modern,
minimal, elegant, academic, technical, creative, executive, and more.

Q: Is it ATS-friendly?
A: Yes. Single-column templates with standard headings parse cleanly through
Workday, Greenhouse, Lever, iCIMS, and Taleo.

Q: Can I export as PDF?
A: Yes. One-click PDF export with embedded fonts. CV + cover letter can be
exported as a single combined PDF.

Q: Does it support cover letters?
A: Yes. 7 cover letter formats that can be paired with any CV template.

Q: Can I switch templates without losing content?
A: Yes. The master profile is separate from templates. Switch freely.

Q: Is there a job tracker?
A: Yes. A kanban board that links each application to the exact CV and cover
letter used.
